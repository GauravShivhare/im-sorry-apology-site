# 🙏 Apology Site - Interactive Multi-Page Website

A mobile-first, interactive multi-page apology website built with **TypeScript** and **Manus** framework. This project delivers a beautifully designed, responsive experience for meaningful apologies with smooth animations and engaging user interactions.

## ✨ Features

- 📱 **Mobile-First Design** - Optimized for all screen sizes and devices
- 🎨 **Interactive UI** - Smooth animations and engaging user interactions
- 🌐 **Multi-Page Experience** - Navigate through multiple apology pages seamlessly
- ⚡ **Built with Manus** - Modern framework for fast and efficient development
- 🎯 **Responsive Layout** - Perfect display across desktop, tablet, and mobile
- 💫 **Smooth Transitions** - Beautiful page transitions and animations

## 🚀 Quick Start

### Prerequisites
- **Node.js** (v18 or higher)
- **pnpm** package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/GauravShivhare/im-sorry-apology-site.git
cd im-sorry-apology-site

# Install dependencies
pnpm install

# Start development server
pnpm dev
```

### Build for Production

```bash
# Create optimized production build
pnpm build

# Preview production build
pnpm preview
```
