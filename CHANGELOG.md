# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-28

### Added
- Initial project setup with Manus framework
- Mobile-first, interactive multi-page apology website
- Complete design system with Soft-Girl Kawaii Stationery theme
- Five-page interactive flow:
  - Entry screen with DM-style interface
  - Welcome page with character illustrations
  - Acknowledgment page with clear statements
  - Key points expandable section (three items)
  - Author message page with mini gallery
  - Letter page with full message reveal
- Responsive design optimized for all devices
- Smooth animations and transitions throughout
- TypeScript strict mode for type safety
- Radix UI components with Tailwind CSS styling
- Live deployment at https://apologyweb-njsz9qd3.manus.space
- Comprehensive README documentation
- Contributing guidelines for developers
- Express.js backend integration
- Vite build configuration with debug logging
- Storage proxy for asset management

### Design Features
- Bandage Coral (`#E87578`) as signature brand color
- Warm ivory paper-like surfaces
- Hand-drawn character illustrations (bunny/cat avatars)
- Floating hearts and sparkle decorations
- Smooth card-based page layouts
- Tactile button interactions with press animations
- Handwritten font (Caveat) for headings
- Rounded clarity font (Nunito) for body text
- Serif contrast font (Fraunces) for special emphasis

### Technical Stack
- **Frontend**: React 19, TypeScript 5.6
- **Styling**: Tailwind CSS 4.1, Custom CSS animations
- **UI Library**: Radix UI components
- **Build Tool**: Vite 7.1
- **Router**: Wouter 3.3
- **Forms**: React Hook Form with Zod validation
- **Icons**: Lucide React 0.453
- **Backend**: Express.js with TypeScript
- **Package Manager**: pnpm 10.4.1
- **Development**: Hot module replacement, TypeScript checking

### Browser Support
- Chrome/Edge 90+
- Firefox 88+
- Safari 14+
- Mobile browsers (iOS Safari, Chrome Mobile)
